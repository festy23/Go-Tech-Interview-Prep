description: Сделай коммит, пуш и открой PR. Conventional commits, Co-Authored-By.
---

Сделай коммит, пуш и открой PR. Пошагово:

1. Запусти `git status` и `git diff --stat` чтобы увидеть все изменения.
2. Проанализируй изменения и составь осмысленное сообщение коммита на английском (conventional commits: feat/fix/refactor/docs/style/chore).
3. Добавь все изменённые файлы через `git add` (конкретные файлы, не `git add .`). Не добавляй .env файлы, node_modules, dist, .DS_Store.
4. Сделай коммит.
5. Запуши в текущую ветку.
6. Если текущая ветка НЕ main/master — открой PR через `gh pr create` с описанием изменений.
7. Если текущая ветка main/master — спроси пользователя, нужно ли создать PR (для этого нужна отдельная ветка).
8. Верни ссылку на PR или подтверждение пуша.
