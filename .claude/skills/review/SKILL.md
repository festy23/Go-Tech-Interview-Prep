Проведи code review незакоммиченных изменений.

## Шаги

1. Запусти `git diff --stat` и `git diff` для полного контекста.

2. Проверь по чеклисту:

### Стиль
- [ ] Tailwind v4: important через суффикс (`bg-red-400!`), НЕ через префикс (`!bg-red-400`)
- [ ] Условные классы через `clsx`, не через конкатенацию строк
- [ ] Используются Carbon design tokens из `@theme` (carbon-*, teal-400, emerald-400, rose-400)
- [ ] Нет хардкод цветов — используй токены

### Типы и схемы
- [ ] Если изменён quizId — обновлены ВСЕ 10 файлов (см. CLAUDE.md)
- [ ] Zod-схемы в shared синхронизированы между question.ts, block.ts, progress.ts
- [ ] Frontend типы совпадают с shared schemas

### i18n
- [ ] Новые строки UI добавлены в ОБА файла: ru.json И en.json
- [ ] Ключи консистентны (quizCard.N.title/subtitle/topics)

### Безопасность
- [ ] Нет .env файлов в коммите
- [ ] SQL-параметры через $1/$2, не конкатенация

### Архитектура
- [ ] Нет дублирования вопросов с существующими квизами
- [ ] Новые компоненты используют существующие паттерны

3. Выведи результат: что ОК, что нужно исправить.
